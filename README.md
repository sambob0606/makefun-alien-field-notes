One line, 145 characters: a review of planet Earth left by an alien tourist, for make.fun's "Alien Field Notes: The Two Day Earth Review" bounty ($2 in USDC). The visitor came for the oceans, stayed for the locals' ghost-costume candy ritual, and would be abducted again.

> Came for the oceans, stayed because the locals dress as ghosts once a year and demand candy from strangers. Five stars — would be abducted again.

## Run it

```sh
python3 -P -s main.py
```

The program writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` when set), one line of 1–200 characters. It needs Python 3 and nothing else; standard library only.
